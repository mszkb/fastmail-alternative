# ADR-0005: Push-Zustellung

- **Status:** Proposed
- **Datum:** 2026-10-02
- **Roadmap:** 0.2, 4.3, 8.1

## Kontext

Benachrichtigung über neue Mails auf iOS-PWA, Android und Desktop, ohne Mailinhalte preiszugeben. Details: [`../architecture/push.md`](../architecture/push.md).

## Optionen

1. **Direkter Web Push (VAPID) aus der Instanz** – keine Drittpartei außer Browser-Push-Dienst.
2. **Über Hosted Push Relay** – nötig für APNs/native App, Komfort für nicht öffentlich erreichbare Instanzen.

## Entscheidung

Vorschlag: **Direkter Web Push als Default und Pflichtfunktion**; Relay optional ab Phase 8. Payload enthält nur Ereignistyp, Installations-ID, Badge.

## Konsequenzen

- Subscription-Modell mit `transport`-Feld (webpush, apns, relay).
- VAPID-Private-Key wird wie ein Secret behandelt.
